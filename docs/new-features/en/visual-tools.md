# Improved visual tools

[New features](README.md) · [Magyar](../hu/visual-tools.md)

**Where to find it:** Video visual toolbar.

**Correct selection**

The position tool moves the actually selected lines.

**X/Y locking**

Constrain movement to an axis and switch with the mouse wheel.

**Center in area**

Center horizontally, vertically, or both inside a rectangle.

**Distance measurement**

Hold the mouse in the cross tool.

**Clean preview**

Hold right-click to temporarily hide visual overlays.
