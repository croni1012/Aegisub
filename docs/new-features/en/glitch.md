# Glitch effect

[New features](README.md) · [Magyar](../hu/glitch.md)

**Where to find it:** Typesetting → Glitch effect.

Add several kinds of glitch effects, then copy or edit them later.

- Added effects remain editable and can be copied.
- Gradients, text boxes, and image masks are supported.

- The effect can be animated, even frame by frame.

## Commands for shortcut settings

- `typesetting/glitch`
