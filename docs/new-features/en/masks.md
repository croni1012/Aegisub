# Create, edit, and generate masks with AI

[New features](README.md) · [Magyar](../hu/masks.md)

**Where to find it:** Video visual toolbar → Mask / Edit mask.

## Create masks

Select an area with a rectangle, points, a brush, or freehand drawing. Aegisub attempts to sample a matching color from the edge.

## Edit masks

Open an existing mask with the complete vector clip toolset including Pipette mode.

## Automatic image mask

With a separate AI connection, complex regions or text embedded in an image can be removed.

AI recognition or removal requires a Cloudinary connection. Check the provider for current pricing and usage allowances.

## Commands for shortcut settings

- `video/tool/mask`
- `video/tool/mask_edit`
