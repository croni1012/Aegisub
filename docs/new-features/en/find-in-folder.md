# Search every subtitle in a folder

[New features](README.md) · [Magyar](../hu/find-in-folder.md)

**Where to find it:** Edit → Find in Folder.

Search subtitle files recursively in a folder and open a result directly at the matching line.

- Search subtitle text and source lines, using whole-word matching or regular expressions.
- Include or exclude styles.

- English source lines appear alongside translations.

**Example**

In a long series, quickly find how a recurring name or phrase was translated in earlier episodes.

## Commands for shortcut settings

- `edit/find_in_folder`
