# Source folders and assigned files

[New features](README.md) · [Magyar](../hu/source-folders.md)

**Where to find it:** Settings: source folders; Subtitle → Load Attached Files.

Add multiple source folders and let Aegisub search them in order for a video with a matching filename.

- A valid absolute video path takes priority.
- The video can still be replaced manually.

- Assigned files can be loaded later from the Subtitle menu.

## Commands for shortcut settings

- `subtitle/loadfiles`
