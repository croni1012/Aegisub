# Motion and Auto motion

[New features](README.md) · [Magyar](../hu/motion.md)

**Where to find it:** Typesetting → Motion.

Auto motion simplifies basic tracking, while Motion adds trimming and built-in image-sequence or video creation. Image masks are supported as well.

- Use Auto motion for quick, basic tracking tasks.
- Trimming can create an image sequence or video directly, with AVI and H.265 support and no separate EXE.

- The workflow supports perspective and a track applied to a separate clip at the same time.
- After saving a Mocha result, Aegisub automatically reads the data from the `.mocha` file.

## Commands for shortcut settings

- `typesetting/motion/auto`
- `typesetting/motion/apply`
- `typesetting/motion/trim`
