# Source lines and convenient MKV loading

[New features](README.md) · [Magyar](../hu/source-lines.md)

**Where to find it:** File → Open MKV; source line in the editor.

When subtitles are opened from a video, each line can receive a persistent source line that remains available after saving.

## What is a source line for?

A translator, editor, or reviewer can see the original sentence next to the translated subtitle without opening another file.

**Example**

A reviewer can compare every translated line with its English source in the same editing view.

## Opening MKV files

The program can load the video and embedded subtitle together. Handling of MKV files containing more than 32 tracks has also been improved.

## Commands for shortcut settings

- `subtitle/open/mkv`
