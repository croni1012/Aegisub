# Shapes and freehand drawing

[New features](README.md) · [Magyar](../hu/shapes.md)

**Where to find it:** Video visual toolbar → Shapes.

Draw rectangles, circles, hearts, and other filled or outlined shapes with customizable line width and corner rounding.

- Freehand drawing for circles and annotations.
- Hold `Alt` to constrain regular proportions.

- Set color and blur directly.

## Commands for shortcut settings

- `video/tool/shape`
