# Quickly run the last script again

[New features](README.md) · [Magyar](../hu/last-script.md)

**Where to find it:** Automation; the shortcut assigned to am/last.

The Last script command repeats the most recently used Automation script. Hotkey command: `am/last`.

**Double press**

Press the assigned key twice quickly to open a list of recently used script actions.

## Commands for shortcut settings

- `am/last`
