# Text box

[New features](README.md) · [Magyar](../hu/text-box.md)

**Where to find it:** Typesetting → Textbox.

The Text box is a separate element that can be edited directly on the video.

- Edit the text box with common formatting controls, including text selection.
- Align text inside the selected area left, center, right, or justified.

- Adjust line spacing independently.
- Works in perspective as well.

- Lines are displayed merged.

## Commands for shortcut settings

- `typesetting/textbox`
