# Pipette mode for complex selections

[New features](README.md) · [Magyar](../hu/clip-eyedropper.md)

**Where to find it:** Vector clip → Eyedropper mode.

Build a selection from colors or AI recognition, then refine it using the brush and edge smoothing.

- Add or remove multiple colors.
- Use the brush in additive or subtractive mode.

- Save settings as reusable templates.
- AI can recognize characters or parts of them.

AI recognition or removal requires a Cloudinary connection. Check the provider for current pricing and usage allowances.
