# Photoshop-style transformations

[New features](README.md) · [Magyar](../hu/transformations.md)

**Where to find it:** Typesetting → Transform.

Use a dedicated preview mode to move, scale, rotate, skew, distort, curve, bend, and mirror subtitle text.

**Free transform**

Move, scale, rotate, and skew.

**Distort**

Fit text to perspective surfaces.

**Curve and bend**

For arced text and curved objects.

**Mirror**

Horizontal and vertical reflection.

**Internal history**

Dedicated undo and redo steps.

**Auto perspective**

Place selected lines in perspective using four points. It follows a customizable yellow reference rectangle; if the active line is a mask, it uses that as the rectangle. After placement, move it within the perspective for fine-tuning.

## Commands for shortcut settings

- `typesetting/transform/free`
- `typesetting/transform/distort`
- `typesetting/transform/auto_perspective`
- `typesetting/transform/arch`
- `typesetting/transform/warp`
