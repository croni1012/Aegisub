# Gradient

[New features](README.md) · [Magyar](../hu/gradient.md)

**Where to find it:** Typesetting → Gradient.

Create complex color gradients directly from the Typesetting menu.

- Choose an angled or radial gradient.
- Select from multiple output types.

- Adjust each color independently with its own ratio using convenient sliders.
- Animate or move the gradient as an effect.

- Lines are displayed merged.

## Commands for shortcut settings

- `typesetting/gradient`
