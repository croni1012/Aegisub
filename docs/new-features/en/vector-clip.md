# Selections, brushes, and multi-line editing

[New features](README.md) · [Magyar](../hu/vector-clip.md)

**Where to find it:** Video visual toolbar → Vector clip / rectangular clip.

The tool can show coordinates, handles multiple shapes, and preserves selections while the video is moved or scaled.

**Delete mode**

## Remove multiple points

Select and delete several control points at once.

**Brush mode**

## Paint additions or subtractions

Expand or reduce the selected area with a brush.

**Multiple lines:** edit clips on several lines at once, including rectangular clips.

## Commands for shortcut settings

- `video/tool/vector_clip`
- `video/tool/clip`
