# Very fast font picker with live preview

[New features](README.md) · [Magyar](../hu/font-picker.md)

**Where to find it:** Font picker in the subtitle editor.

The font list uses a cache that needs rebuilding when your fonts change. The picker remembers its window position and lets you search anywhere in a font name.

## Filter and organize

- Hungarian, kanji, and custom character-set filters.
- Optional hiding of @ fonts.

- Recent, frequently used, favorites, temporary, and custom lists.

## Try it immediately

Selected subtitle lines update live. Adjust `\fs`, `\fscx`, `\fscy`, `\fsp`, and common text styles while previewing.

**Custom sample text:** change it under Settings → Interface.

## Commands for shortcut settings

- `edit/font`
