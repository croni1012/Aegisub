# Pick colors with a hotkey

[New features](README.md) · [Magyar](../hu/color-picker.md)

**Where to find it:** Video preview; shortcuts assigned to the color picker commands.

Insert the color under the mouse directly as a `\c`, `\3c`, or `\4c` tag. Command: `video/colorpick/primary|outline|shadow`.

## Single activation

Inserts the sampled color using the chosen color tag.

## Double activation

Opens a magnified picker, can create scene-aligned `\t(...)` tags, and can load motion data.

## Commands for shortcut settings

- `video/colorpick/primary`
- `video/colorpick/outline`
- `video/colorpick/shadow`
