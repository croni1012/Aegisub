# Image insertion with editing

[New features](README.md) · [Magyar](../hu/image-editor.md)

**Where to find it:** Typesetting → Image insert → With editing.

A Photoshop-like editor opens with the current video frame and each selected subtitle line on its own layer.

- Each selected subtitle line appears as an individual layer.
- The editing tools work as you would expect from Photoshop or in a similar way.

- The visible result replaces the selected lines and is inserted into the subtitle as an image mask.
- For example, it can provide free content-aware removal.

## Commands for shortcut settings

- `typesetting/image_insert/edit`
