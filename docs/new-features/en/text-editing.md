# Replace text and turn selections into comments

[New features](README.md) · [Magyar](../hu/text-editing.md)

**Where to find it:** Subtitle grid → right-click → Change text; text editor context menu.

**Replace text**

## Across selected lines

Gradient tags are recognized and redistributed proportionally over the replacement text.

**Comment**

## Only the selected text

Use the context menu to comment or restore a text selection. The shortcut command is `edit/comment`.

## Commands for shortcut settings

- `edit/line/change-text`
- `edit/comment`
