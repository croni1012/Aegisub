# Képbeillesztés szerkesztéssel

[Új funkciók](README.md) · [English](../en/image-editor.md)

**Hol találod:** Formázás → Képbeillesztés → Szerkesztéssel.

Photoshop-szerű szerkesztő nyílik meg az aktuális képkockával és a kijelölt sorok külön rétegeivel.

- A kijelölt sorok egyenkénti rétegként jelennek meg.
- A szerkesztés a Photoshopban megszokott módon vagy ahhoz hasonlóan működik.

- A látható végeredmény a kijelölt sorok felülírásával képmaszkként kerül a feliratba.
- Használható például ingyenes, tartalomérzékeny kitakarásra.

## Gyorsbillentyűhöz kereshető parancsok

- `typesetting/image_insert/edit`
