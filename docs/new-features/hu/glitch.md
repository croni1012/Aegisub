# Glitch effekt

[Új funkciók](README.md) · [English](../en/glitch.md)

**Hol találod:** Formázás → Glitch effekt.

Többféle glitch effektet adhatsz hozzá, amelyeket később is másolhatsz és szerkeszthetsz.

- A hozzáadott effektek később módosíthatók és másolhatók.
- Gradientet, szövegdobozt és képmaszkot is támogat.

- Az effekt animálható, akár képkockánként is.

## Gyorsbillentyűhöz kereshető parancsok

- `typesetting/glitch`
