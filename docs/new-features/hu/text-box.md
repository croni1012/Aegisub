# Szövegdoboz

[Új funkciók](README.md) · [English](../en/text-box.md)

**Hol találod:** Formázás → Szövegdoboz.

A Szövegdoboz külön elemként jelenik meg, és a videón közvetlenül szerkeszthető.

- A szövegdoboz általános formázásokkal és kijelölt szövegrésszel is szerkeszthető.
- A szöveg a kijelölt területen belül balra, középre, jobbra vagy sorkizártan rendezhető.

- A sortávolság külön módosítható.
- Perspektívában is működik.

- A sorok összevonva jelennek meg.

## Gyorsbillentyűhöz kereshető parancsok

- `typesetting/textbox`
