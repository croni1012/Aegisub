# Színkijelölés egy gyorsgombbal

[Új funkciók](README.md) · [English](../en/color-picker.md)

**Hol találod:** Videó-előnézet; a színkijelölő parancsokhoz rendelt gyorsbillentyűk.

Az egér alatti szín közvetlenül beilleszthető `\c`, `\3c` vagy `\4c` tagként. A parancs: `video/colorpick/primary|outline|shadow`.

## Egyszeri aktiválás

Az egér alatti színt a kiválasztott színtagként szúrja be.

## Dupla aktiválás

Nagyított mintavételi nézetet nyit, jelenethez igazított `\t(...)` tagot készíthet, és motion adatot is betölthet.

## Gyorsbillentyűhöz kereshető parancsok

- `video/colorpick/primary`
- `video/colorpick/outline`
- `video/colorpick/shadow`
