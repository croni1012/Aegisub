# Apróbb, de hasznos változtatások

[Új funkciók](README.md) · [English](../en/other-improvements.md)

**Hol találod:** Időzítés, videóbetöltés és videó-előnézet.

- `video/open/recent` parancs a legutóbbi videó betöltéséhez.
- 32-nél több fájlt tartalmazó MKV-k megbízhatóbb megnyitása.

- Sorok eltolása az aktuális képkockához a végidejük alapján.
- A videó nem villog méretezés közben.

## Gyorsbillentyűhöz kereshető parancsok

- `time/frame/current_end`
- `video/open/recent`
