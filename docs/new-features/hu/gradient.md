# Gradient

[Új funkciók](README.md) · [English](../en/gradient.md)

**Hol találod:** Formázás → Gradient.

A Gradient funkcióval összetett színátmeneteket készíthetsz közvetlenül a Formázás menüből.

- Választhatsz szögbeállításos vagy sugaras gradientet.
- Többféle output közül választhatsz.

- A színeket külön-külön, saját arányokkal állíthatod egyszerre, kényelmes csúszkákkal.
- A gradient animálható és mozgatható effektként is használható.

- A sorok összevonva jelennek meg.

## Gyorsbillentyűhöz kereshető parancsok

- `typesetting/gradient`
