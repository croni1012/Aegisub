# Szövegcsere és megjegyzésbe rakás

[Új funkciók](README.md) · [English](../en/text-editing.md)

**Hol találod:** Feliratrács → jobb kattintás → Szövegcsere; szövegszerkesztő helyi menüje.

**Szövegcsere**

## Több kijelölt sor egyszerre

A gradientet is felismeri, és az új szövegre arányosan próbálja visszaírni.

**Megjegyzés**

## Csak a kijelölt szövegrész

Jobb klikkel megjegyzésbe tehető és visszaalakítható. Bindelheted is: `edit/comment`.

## Gyorsbillentyűhöz kereshető parancsok

- `edit/line/change-text`
- `edit/comment`
