# Pipetta mód összetett kijelölésekhez

[Új funkciók](README.md) · [English](../en/clip-eyedropper.md)

**Hol találod:** Vector clip → Pipetta mód.

Színek alapján készíthetsz kijelölést vagy AI felismerést alkalmazhatsz, amit ecsettel, élsimítással és egyebekkel finomíthatsz.

- Több szín hozzáadható vagy eldobható.
- Az ecset hozzáadó és kivonó módban is működik.

- A beállítások sablonba menthetők és visszatölthetők.
- Az AI karaktereket vagy azok részeit is felismerheti.

Az AI-alapú felismeréshez vagy eltávolításhoz Cloudinary-kapcsolat szükséges. A szolgáltatás aktuális díjai és használati keretei a szolgáltatónál ellenőrizhetők.
