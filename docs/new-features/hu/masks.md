# Maszk létrehozása, szerkesztése és AI-s eltávolítás

[Új funkciók](README.md) · [English](../en/masks.md)

**Hol találod:** Videó vizuális eszköztára → Maszk / Maszk szerkesztése.

## Maszk létrehozása

Téglalappal, pontokkal, ecsettel vagy szabadkézzel jelölhetsz ki területet. A program megpróbálja a terület széléről automatikusan kiválasztani a színt.

## Maszk szerkesztése

A meglévő maszk a vector clip teljes eszköztárával javítható, Pipetta móddal együtt.

## Automatikus képmaszk

Külön AI-kapcsolattal bonyolult terület vagy képen lévő szöveg is eltávolítható.

Az AI-alapú felismeréshez vagy eltávolításhoz Cloudinary-kapcsolat szükséges. A szolgáltatás aktuális díjai és használati keretei a szolgáltatónál ellenőrizhetők.
