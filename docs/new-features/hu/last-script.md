# Az utolsó script gyors újrafuttatása

[Új funkciók](README.md) · [English](../en/last-script.md)

**Hol találod:** Automatizálás; az am/last parancshoz rendelt gyorsbillentyű.

Az Utolsó script parancs elindítja a legutóbb használt scriptet. Gyorsgombja: `am/last`.

**Dupla lenyomás**

A hozzárendelt billentyű gyors kétszeri megnyomása listát nyit az utoljára használt scriptlehetőségekből.

## Gyorsbillentyűhöz kereshető parancsok

- `am/last`
