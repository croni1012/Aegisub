# Dark mód és testreszabható színek

[Új funkciók](README.md) · [English](../en/dark-mode.md)

**Hol találod:** Beállítások → Felhasználói felület; színbeállítások.

A Dark mód külön kapcsolható be, új ikonokkal és külön testreszabható színekkel.

- A sötét megjelenést külön engedélyezheted.
- Az új ikonokkal egységesebb és könnyebben áttekinthető a felület.

- A felület színei külön testreszabhatók.

## Gyorsbillentyűhöz kereshető parancsok

- `app/options`

> A külön sötétmód-kapcsoló wxWidgets 3.3 vagy újabb verzióval készült buildben érhető el.
