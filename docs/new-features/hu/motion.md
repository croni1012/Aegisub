# Motion és Auto motion

[Új funkciók](README.md) · [English](../en/motion.md)

**Hol találod:** Formázás → Motion.

Az Auto motion az alapvető mozgáskövetést egyszerűsíti, a Motion pedig trimmeléssel és beépített képsorozat- vagy videókészítéssel egészül ki. Képmaszkokat is támogat.

- Az Auto motion alapvető feladatokra gyorsan használható.
- A trimmelés beépített képsorozatot vagy videót készít, AVI és H.265 támogatással, külön EXE nélkül.

- A meglévő script a perspektívát és a külön clipre futtatott tracket is támogatja.
- Mocha-eredménynél mentés után a program automatikusan beolvassa az adatokat a `.mocha` fájlból.

## Gyorsbillentyűhöz kereshető parancsok

- `typesetting/motion/auto`
- `typesetting/motion/apply`
- `typesetting/motion/trim`
