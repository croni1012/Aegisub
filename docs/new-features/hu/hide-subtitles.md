# Feliratsorok vagy csak maszkok elrejtése

[Új funkciók](README.md) · [English](../en/hide-subtitles.md)

**Hol találod:** Videóablak helyi menüje és eszköztára.

A megjegyzésállapot módosítása nélkül elrejtheted az összes sort, vagy külön csak a `\p1`-es maszkokat a videó felületen ideiglenesen. Az áttetszőség is állítható.

## Gyorsbillentyűhöz kereshető parancsok

- `video/toggle_mask`
- `video/toggle_subtitle`
