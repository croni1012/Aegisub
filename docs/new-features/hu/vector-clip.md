# Kijelölés, ecset és többsoros szerkesztés

[Új funkciók](README.md) · [English](../en/vector-clip.md)

**Hol találod:** Videó vizuális eszköztára → Vector clip / téglalapos clip.

Az eszköz koordinátákat mutathat, több alakzatot kezel, és a kijelölés a videó mozgatása közben is megmarad.

**Delete mód**

## Több pont törlése

Egyszerre több vezérlőpont jelölhető ki és törölhető.

**Brush mód**

## Ecsetes hozzáadás és kivonás

Festéssel bővítheted vagy szűkítheted a kijelölt területet.

**Többsoros szerkesztés:** több sor clipje egyszerre módosítható, téglalapos clip esetén is.

## Gyorsbillentyűhöz kereshető parancsok

- `video/tool/vector_clip`
- `video/tool/clip`
