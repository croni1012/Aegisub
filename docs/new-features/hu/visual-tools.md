# Javított vizuális eszközök

[Új funkciók](README.md) · [English](../en/visual-tools.md)

**Hol találod:** Videó vizuális eszköztára.

**Pontos kijelölés**

A pozíciós eszköz ténylegesen a kijelölt sorokat mozgatja.

**X/Y zárolás**

A mozgás tengelyhez köthető és görgővel is váltható.

**Középre rendezés**

Kijelölt téglalapon belül vízszintesen vagy függőlegesen.

**Távolságmérés**

A kereszt eszközzel egérnyomva tartás közben.

**Tiszta kép**

Jobb kattintás nyomva tartására eltűnnek a vizuális jelölések.
